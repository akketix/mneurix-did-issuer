## We are not accepting external pull requests

This repository does not accept external code contributions. Pull requests from
forks will be closed. This is intentional: the engine is published for
**inspection + self-hosting** (the trust model — you can read every line and
verify there is no phone-home, no DRM, no hidden egress), not for open
collaboration. The commercial product line + roadmap are managed privately.

If you find a **security issue**, please report it privately — see
[`SECURITY.md`](./SECURITY.md). For **commercial licensing** or other
questions, see the contact details in [`LICENSING.md`](./LICENSING.md).

## Forking

You may fork this repository for your own self-hosted use under ELv2. Forks
are personal copies and do not affect this project. Re-hosting a fork as a
managed service for third parties requires a commercial license (ELv2 §3).
